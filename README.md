# GPS Safety Jewellery Wearable  Companion App

A Flutter-based companion application for the GPS Safety Jewellery 
Wearable system, designed to improve personal safety for women 
in urban Kenya.

## Features
-  Shake-to-alert emergency trigger
-  Real-time location sharing on map
- BLE beacon detection from pendant hardware
-  Emergency contact management
-  Alert history and status tracking
-  DPA 2019 compliant : coordinates auto-deleted after 24h

## Tech Stack
| Layer | Technology |
|---|---|
| Frontend | Flutter / Dart |
| Backend | Python / FastAPI |
| Database | Supabase PostgreSQL |
| Maps | Flutter Map / Mapbox |
| SMS | Africa's Talking API |
| Auth | Supabase Auth |
